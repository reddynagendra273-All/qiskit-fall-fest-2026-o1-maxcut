# Qiskit Fall Fest 2026 — O1 Max-Cut

## Project Overview

This project focuses on the O1 Max-Cut problem for Qiskit Fall Fest 2026 Phase 1.

The objective is to divide the vertices of a graph into two groups while maximizing the number or total weight of edges crossing between the groups.

## Objectives

* Implement the required Max-Cut solution.
* Run the same solution using the official Processor A and Processor B configurations.
* Measure and compare the required metrics.
* Document the experiments so they can be reproduced.

## Status

Repository setup in progress. The implementation will follow the official O1 Challenge Kit.
